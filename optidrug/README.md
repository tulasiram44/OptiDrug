# 💊 OptiDrug: AI-Based Bioinformatics Platform for Drug Candidate Prioritization

**OptiDrug** is an artificial intelligence-driven bioinformatics platform designed to help researchers prioritize small-molecule drug candidates for target diseases using a biologically grounded pipeline, quantitative structure-activity relationship (QSAR) machine learning, and multi-objective mathematical optimization.

---

## 🧬 Biological Grounding Pipeline

The platform enforces a rigorous hierarchical discovery cascade:

$$\text{Disease} \longrightarrow \text{Gene} \longrightarrow \text{Protein} \longrightarrow \text{Drug Target Pocket} \longrightarrow \text{Candidate Compounds}$$

## 🧪 Data Cleaning & Preprocessing Pipeline

Every candidate dataset undergoes an automated 5-stage quality assurance pipeline:
1. **Duplicate Removal**: Identifies and prunes duplicate chemical structures and identifiers.
2. **Missing Value Imputation**: Imputes missing molecular descriptor values using medians learned strictly from training data.
3. **Categorical Scaffold Encoding**: One-hot encodes medicinal chemistry scaffolds (e.g., Quinazolines, Pyrazolopyrimidines).
4. **Feature Normalization**: Rescales all continuous descriptors to a $[0, 1]$ interval via `MinMaxScaler` fitted exclusively on training sets.
5. **80/20 Train/Test Split**: Enforces reproducible, leak-free validation splits.

## 🤖 Machine Learning Model: Random Forest Regression

- **Model**: `RandomForestRegressor` (100 estimators, max depth 6)
- **Target**: Computational Activity Score ($0.0 - 1.0$) and biological bioactivity ($\text{pIC}_{50} = -\log_{10}[\text{IC}_{50}]$).
- **Held-Out Test Performance**:
  - $R^2 \approx 0.58$ (Variance explained in held-out test data)
  - $\text{MAE} \approx 0.075$ (Mean Absolute Error)
  - Pearson correlation $r \approx 0.76$
- **Explainability**: Quantifies Mean Decrease in Impurity (MDI) feature importances and localized contribution scores for each candidate compound.

## ⚖️ Multi-Objective Mathematical Optimization

Real-world drug candidates must balance potency against safety, drug-drug interaction risk, cost, and drug-likeness. OptiDrug integrates three optimization paradigms:

1. **Weighted Sum Model (WSM)**:
   $$\text{Composite Score} = w_{\text{eff}} \cdot \text{Eff} + w_{\text{safe}} \cdot (1 - \text{Tox}) + w_{\text{inter}} \cdot (1 - \text{CYP}) + w_{\text{cost}} \cdot (1 - \text{Cost}) + w_{\text{drug}} \cdot (1 - \text{Viol})$$

2. **Derringer-Suich Geometric Desirability ($D$)**:
   $$D = \left( \prod_{i=1}^k d_i^{w_i} \right)^{\frac{1}{\sum w_i}}$$

3. **Pareto Dominance Frontier**:
   Identifies the non-dominated Pareto set where candidates cannot improve in one attribute without sacrificing another.
